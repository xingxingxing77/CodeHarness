## 3. 会话详情页（核心界面）与 BUI 组件映射

```
┌ sidebar-nav ─ 会话列表 ┐ ┌────────── 消息流 ──────────────┐
│ search / entity-chip   │ │ user 气泡 / assistant 消息      │
├────────────────────────┤ │   streaming-text（assistant_delta）│
│ 会话标题 + 状态条        │ │   tool-chips（运行中/完成）      │
│ compact/status 提示     │ │   task-rows（工具执行明细）      │
├────────────────────────┤ │   diff-table（写文件类 ui）      │
│ prompt-bar / chat-     │ │   code-block（代码/终端输出）     │
│ composer（输入区）       │ │  [approval-card（挂起时置顶）]    │
└────────────────────────┘ └────────────────────────────────┘
```

### SSE 事件 → BUI 组件映射（消费契约④九种事件）

| SSE 事件 | 渲染组件 | 交互细节 |
|---|---|---|
| `assistant_delta` | `streaming-text` / `stream-text`(atom) | 打字机追加；词级 blur-in 动效按组件内建节奏 |
| `assistant_turn_complete` | 消息组件落定 | 用表内 `message` 替换流式缓冲；metadata.stop_reason 仅角标提示 |
| `tool_started` | `tool-chips` + `task-rows` | chip 置"运行中"（`shimmer` 占位） |
| `tool_completed` | `task-rows` + 按 `ui.kind` 分发 | `diff`→`diff-table`；`terminal`→`code-block`；`file`→预览卡；`ui=null` 仅显示 output 摘要 |
| `compact_progress` | 状态条 | `loading-state` 微光提示"压缩对话记忆中" |
| `approval_required` | `approval-card` | 弹层置顶 + `/approvals` 角标；items 渲染 tool_name/input_preview/risk_level；决策按钮 → `POST /runs/{rid}/approvals/{tid}/decide` |
| `status` | 状态条 | `thinking-state`（如"网络波动，正在重试…"） |
| `error` | toast + 消息内错误条 | error.code 映射文案（见接口文档错误码表） |
| `run_finished` | 结束态 | usage 三值展示；输入区解锁 |

## 4. 状态管理与数据流

```
React Query（REST）                     SSE reducer（事件流 → 会话状态机）
├─ sessions/messages/approvals 缓存     ├─ useChatStream(sid) 订阅 /sessions/{sid}/events
├─ mutations: 发消息/决策/取消           ├─ EventSource 封装：Last-Event-ID 自动续传
└─ 失效联动：run_finished → invalidate  ├─ 事件按 type 归约：messages[]、runningTools{}、
   messages/approvals                    │   pendingApproval、status、usage
                                        └─ 到 run_finished 置 idle 并触发 React Query 失效
```

- **发送消息**：`POST /sessions/{sid}/messages` 拿 `run_id` → 打开/复用 SSE 订阅 → 事件归约渲染；
- **断线重连**：EventSource 自动带 `Last-Event-ID`；服务端从 Redis Stream 该 entry id 起重放——不丢不重（契约保证）；
- **刷新恢复**：进页先 `GET /messages`（事实源）拉全量，再从 `after=<当前 Stream 尾>` 订阅增量；挂起态由 `GET /approvals?status=pending` 恢复审批卡；
- **多标签/多设备**：同一会话多处订阅同一 Stream，天然同步；审批在任一处决策，其余端经 `run_finished`/后续事件自然续播。

## 5. 目录结构（web/）

```
web/src/
├── app/(routes)/           # §1 页面
├── components/bui/         # BUI 组件（atoms/primitives/平铺）
├── components/chat/        # 业务组件：MessageList/ToolCard/ApprovalLayer/StatusBar
├── hooks/useChatStream.ts  # SSE 订阅 + reducer（唯一事件消费点）
├── lib/api.ts              # REST 客户端（契约⑥ typed）
├── lib/types.ts            # Message/ContentBlock/SSEEvent 类型（与契约文档一一对应）
└── stores/session.ts       # 轻量跨组件状态（Zustand，仅会话 UI 态）
```

防火墙：`lib/types.ts` 手写镜像契约④/⑥ 类型，不 import 任何后端/框架生成物；接口变更以契约文档为准同步此文件。
