## 权威归属总表

| 主题 | 权威文档 | 不得另写处 |
|---|---|---|
| 接口 schema / SSE 事件 / 错误码 | 接口契约 | 前后端实现文档只引用 |
| 消息/事件/审批等领域模型语义 | 后端设计 + 各展开篇 | 接口契约只承载传输形态 |
| 布局与交互决策（含否决记录） | UX布局设计 | 页面清单等数据面归前端设计 |
| 视觉令牌使用规则 | UI设计规范 | 组件内禁私有 hex |
| 表结构 / Redis key / 保留策略 | 数据库设计 | 各设计文档只引用 |
| 阶段范围 / 关键设计决策 | 设计计划 | 变更在此登记 |
| 环境变量 | 配置清单 | 代码装配层外的文档引用此处 |

## 变更规则

1. **接口变更**：先改 [接口契约] → 更新 `web/src/lib/types.ts` 镜像 → 冒烟/测试锁定 → 实现；
2. **决策变更**（方案/依赖/边界取舍）：在 [设计计划 §五] 登记，注明日期与理由；
3. **新 env**：先入 [配置清单] 再写代码；
4. **新平台类型**：必须进 `engine/serde.py` checkpoint 白名单（见[开发指南 §6 已知坑]）。
