# 内置工具规范

> M1 五个内置工具的唯一定义源：实现照本文写，测试照本文断言。通用契约（ToolDef/ToolCall/ToolResult/五闸门/回执规则）见 [后端设计 §4](后端设计.md)；沙箱执行细节见[权限与沙箱设计](权限与沙箱设计.md)。
> 关联：[接口契约](../接口文档/接口契约.md)（ContentBlock/ui payload 消费方）· [UX布局设计](../前端文档/UX布局设计.md)（工具卡渲染）

## 1. 通用约定

每个工具以 `ToolDef` 注册（`tools/base.py`），必填声明：

```python
@dataclass(frozen=True)
class ToolDef:
    name: str
    description: str
    input_model: type[BaseModel]        # ③ 闸门的 pydantic schema（同时生成 Anthropic input_schema）
    parallel_safe: bool                 # 并行分区依据（后端设计 §4）
    is_read_only: Callable[[BaseModel], bool]   # ④ 闸门动态定级
    executes_commands: bool = False     # 是否吃命令行（cmd_* 规则仅对此类生效）
    ui_kind: str | None = None          # 完成态 ui payload 种类：diff|terminal|file|None
```

- 路径类参数统一走 resolver（`file_path/path/root` 探测 → `/workspace` 内 realpath）；工具内部**不得**二次解析；
- 失败一律转 `is_error` 回执喂回模型（五类失败清单见后端设计）；输出超 `inline_limit_chars`（默认 8000）触发 spill（"完整 URI + 预览 + 原始大小"回执）；
- 工具执行全部经 `SandboxHandle`（S1.1），凭证/env 白名单由沙箱管线负责。

## 2. read_file

| 项 | 定义 |
|---|---|
| 描述 | 读取工作区内文本文件的一个行区间，带行号返回 |
| input_schema | `{ "file_path": str(必填), "offset": int=0（起始行，0 基）, "limit": int=200（最多行数，≤1000） }` |
| parallel_safe / read_only | `true` / `true`（恒只读） |
| 执行 | `sandbox.read_file(container_path)` → 按 `\n` 切行取 `[offset, offset+limit)`，行号 1 基渲染 |
| 输出 | `cat -n` 风格：`     1\timport os`；文件末尾附 `[truncated: showing lines 1-200 of 1843]` 提示 |
| 错误回执 | 越界=PathEscape → `Permission denied for read_file: path escapes workspace: {path}`；不存在 → `File not found: {path}`；二进制 → `Binary file (media_type), use export instead` |
| ui | 无（正文即回执） |

## 3. write_file

| 项 | 定义 |
|---|---|
| 描述 | 全量写/覆盖工作区内文件（编辑 = 读后改写全量，M1 不做部分编辑） |
| input_schema | `{ "file_path": str(必填), "content": str(必填) }` |
| parallel_safe / read_only | `false` / `false`（恒写） |
| 执行 | 先 `read_file` 取现文（可空）→ `sandbox.write_file` → 产出 diff |
| 输出（content 给模型） | `Wrote 42 lines to src/app/main.py (+12/-3 vs previous)`（统计行，不含全文） |
| ui（给前端） | `{ "kind": "diff", "data": { unified_diff } }` → 前端 `diff-table`；永不进模型上下文 |
| 错误回执 | 同 read_file 路径错误；目录不存在自动创建；只读 fs → sandbox 层失败 `write failed: {err}` |
| 配方交互 | 标准配方：工作区内 ALLOW、工作区外 DENY；谨慎配方一律要批（写操作天然非只读） |

## 4. glob

| 项 | 定义 |
|---|---|
| 描述 | 按模式匹配文件路径，按修改时间新→旧排序 |
| input_schema | `{ "pattern": str(必填, 如 "src/**/*.py"), "path": str="."（相对工作区根） }` |
| parallel_safe / read_only | `true` / `true` |
| 执行 | 容器内 ripgrep `--files` + 过滤（`fd` 等价），结果上限 200 条，超出附 `(+N more)` |
| 输出 | 每行一个相对路径；空结果回 `No files match pattern: {pattern}`（is_error=false） |
| 错误回执 | path 越界 → PathEscape 回执；非法 pattern → `Invalid glob pattern: {err}` |

## 5. grep

| 项 | 定义 |
|---|---|
| 描述 | 正则搜索文件内容（ripgrep 语义），返回 命中行 |
| input_schema | `{ "pattern": str(必填, Rust regex), "path": str=".", "include": str=可以 glob 过滤文件名（如 "*.py"）, "max_results": int=50（≤200） }` |
| parallel_safe / read_only | `true` / `true` |
| 执行 | 容器内 `rg -n --glob {include} {pattern} {path}` |
| 输出 | `{path}:{lineno}: {line}`，每文件首命中组间空行；截断附 `(+N more matches)` |
| 错误回执 | 非法正则 → `Invalid regex: {err}`（原样喂回让模型改写）；零命中 → `No matches for: {pattern}`（非错误） |
| ui | 无 |

## 6. bash

| 项 | 定义 |
|---|---|
| 描述 | 在沙箱内执行 shell 命令（经 jail 包装器，网络禁用、资源限额） |
| input_schema | `{ "command": str(必填), "timeout_s": int=120（≤300） }` |
| parallel_safe / read_only | `false` / **按输入动态定级**：纯读白名单前缀（`ls/cat/head/tail/wc/find/grep/git status/git log/git diff`）= true，其余 = false |
| executes_commands | `true`（cmd_* 规则的作用对象；危险清单见权限与沙箱 §1.5） |
| 执行 | `sandbox.exec(["/usr/local/bin/jail", "bash", "-c", command])`；stdout/stderr 合流按序捕获 |
| 输出 | 原始输出 + 尾行 `<exit code: {n}>`；truncated 附 spill 引用 |
| 错误回执 | 非零退出**不是** is_error（命令失败是正常观察数据）；jail 拒绝（提权二进制）、超时、沙箱失联才置 is_error |
| ui | `{ "kind": "terminal" }` → 前端 `code-block` |

## 7. 与权限配方的交互矩阵（标准配方示例）

| 工具×操作 | 决策 |
|---|---|
| read_file / glob / grep（任意工作区内路径） | ALLOW |
| write_file 工作区内 | ALLOW |
| write_file 工作区外 | DENY（围栏）——模型收到 reason 后改道 |
| bash 纯读命令 | ALLOW |
| bash 其他（pip install、git commit…） | REQUIRE_CONFIRM（risk=medium） |
| bash 危险清单（sudo、rm -rf /、curl\|bash） | DENY |

谨慎/托管配方整体覆盖规则见[权限与沙箱设计 §1.5](权限与沙箱设计.md)。

## 8. 测试基线（每工具必过）

1. schema 校验失败 → `Invalid input for {tool}` 回执（非异常）；
2. 路径逃逸 → DENY 回执 + 审计事件；
3. 正常路径 → 回执含约定格式（行号/统计/diff ui）；
4. 超长输出 → spill 引用回执；
5. fake 沙箱（`engine/testing.py`）驱动，不依赖 Docker；Docker 级用例见[权限与沙箱 §2.8](权限与沙箱设计.md)。
