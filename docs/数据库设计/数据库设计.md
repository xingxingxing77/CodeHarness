# 数据库设计

> Postgres（事实源 + LangGraph checkpoint + pgvector 记忆）与 Redis（队列/事件/锁/通知，不做业务存储）。
> 关联：[后端设计](../后端文档/后端设计.md) · [接口契约](../接口文档/接口契约.md)

## 1. ER 总览

```
tenants 1─* users
tenants 1─* sessions 1─* messages（事实源）
sessions 1─* runs 1─* approvals（工单）
tenants 1─* credentials（供应商凭证，加密）
tenants 1─* memories（pgvector 语义记忆）
runs 1─1 langgraph_checkpoints（thread_id = run_id）
```

## 2. Postgres 表 DDL

```sql
-- 租户与用户
CREATE TABLE tenants (
    id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    name        text NOT NULL,
    quotas      jsonb NOT NULL DEFAULT '{}',      -- {max_concurrent_runs, tokens_per_day, ...}
    created_at  timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE users (
    id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id  uuid NOT NULL REFERENCES tenants(id),
    subject    text NOT NULL,                     -- OIDC sub / 用户名
    role       text NOT NULL DEFAULT 'member',    -- owner|admin|member
    UNIQUE (tenant_id, subject)
);

-- 会话（对应契约⑥ Session）
CREATE TABLE sessions (
    id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id    uuid NOT NULL REFERENCES tenants(id),
    title        text NOT NULL DEFAULT '',
    model        text NOT NULL,
    sandbox_image text,
    archived     boolean NOT NULL DEFAULT false,
    session_state jsonb NOT NULL DEFAULT '{}',    -- SessionState（goals/artifacts/work_log/...）
    created_at   timestamptz NOT NULL DEFAULT now(),
    updated_at   timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_sessions_tenant ON sessions(tenant_id, updated_at DESC) WHERE archived = false;

-- 消息（事实源；写穿提交点：agent 终态后 / execute 回执后）
CREATE TABLE messages (
    id          bigserial PRIMARY KEY,             -- keyset 分页游标
    session_id  uuid NOT NULL REFERENCES sessions(id),
    run_id      uuid NOT NULL,
    role        text NOT NULL CHECK (role IN ('user','assistant')),
    content     jsonb NOT NULL,                    -- ContentBlock[]（text/image/tool_call/tool_result）
    metadata    jsonb NOT NULL DEFAULT '{}',       -- stop_reason 等（仅供 UI，不参与路由）
    created_at  timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_messages_session ON messages(session_id, id);

-- run（一次 run 的状态机）
CREATE TABLE runs (
    id          uuid PRIMARY KEY,                  -- = LangGraph thread_id
    session_id  uuid NOT NULL REFERENCES sessions(id),
    tenant_id   uuid NOT NULL REFERENCES tenants(id),
    kind        text NOT NULL DEFAULT 'new' CHECK (kind IN ('new','resume')),
    status      text NOT NULL DEFAULT 'queued' CHECK (status IN ('queued','running','interrupted','succeeded','failed','cancelled')),
    usage_input  bigint NOT NULL DEFAULT 0,
    usage_output bigint NOT NULL DEFAULT 0,
    error        jsonb,                            -- {code, message}
    max_turns    int NOT NULL DEFAULT 200,
    created_at   timestamptz NOT NULL DEFAULT now(),
    finished_at  timestamptz
);
CREATE INDEX idx_runs_session ON runs(session_id, created_at DESC);
CREATE INDEX idx_runs_active  ON runs(session_id) WHERE status IN ('queued','running','interrupted');

-- 审批工单（permissions/approval.py 的持久形态）
CREATE TABLE approvals (
    ticket_id   text PRIMARY KEY,                  -- 'ap-' + hash(run_id, sorted(call_ids))[:16]
    run_id      uuid NOT NULL REFERENCES runs(id),
    session_id  uuid NOT NULL REFERENCES sessions(id),
    items       jsonb NOT NULL,                    -- ApprovalItem[]（tool_name/input_preview/risk_level/reason）
    status      text NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','decided','expired')),
    decision    jsonb,                             -- ApprovalDecision（未覆盖 call fail-closed）
    decided_by  text,
    created_at  timestamptz NOT NULL DEFAULT now(),
    expires_at  timestamptz NOT NULL,              -- 默认 +30min；到期 decision 端按 410 拒绝
    decided_at  timestamptz
);
CREATE INDEX idx_approvals_pending ON approvals(session_id, created_at DESC) WHERE status = 'pending';

-- 权限规则（tenant 级默认 + session 级覆盖；匹配顺序与配方语义见 后端文档/权限与沙箱设计.md §一）
CREATE TABLE permission_rules (
    id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id  uuid NOT NULL REFERENCES tenants(id),
    scope      text NOT NULL DEFAULT 'tenant' CHECK (scope IN ('tenant','session')),
    session_id uuid REFERENCES sessions(id),
    kind       text NOT NULL CHECK (kind IN ('tool_allow','tool_deny','path_allow','path_deny','cmd_allow','cmd_deny')),
    pattern    text NOT NULL,
    risk_level text NOT NULL DEFAULT 'medium',
    priority   int  NOT NULL DEFAULT 100,
    enabled    boolean NOT NULL DEFAULT true,
    created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_rules_lookup ON permission_rules(tenant_id, scope, session_id, priority) WHERE enabled;

-- 供应商凭证（写即加密；响应永不回显明文）
CREATE TABLE credentials (
    id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id   uuid NOT NULL REFERENCES tenants(id),
    provider    text NOT NULL,                     -- anthropic|openai|codex|copilot|...
    label       text NOT NULL DEFAULT '',
    secret_enc  bytea NOT NULL,                    -- AES-GCM(kms/主密钥)
    meta        jsonb NOT NULL DEFAULT '{}',       -- base_url、enterprise_url、过期时间等
    created_at  timestamptz NOT NULL DEFAULT now(),
    UNIQUE (tenant_id, provider, label)
);

-- 语义记忆（P3，需 CREATE EXTENSION vector）
CREATE TABLE memories (
    id          bigserial PRIMARY KEY,
    tenant_id   uuid NOT NULL REFERENCES tenants(id),
    session_id  uuid REFERENCES sessions(id),      -- 可选来源会话
    kind        text NOT NULL DEFAULT 'fact',      -- fact|preference|procedure
    content     text NOT NULL,
    embedding   vector(1536) NOT NULL,
    meta        jsonb NOT NULL DEFAULT '{}',
    created_at  timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_memories_ann ON memories USING hnsw (embedding vector_cosine_ops);
CREATE INDEX idx_memories_tenant ON memories(tenant_id, created_at DESC);

-- 审计（hooks 事件总线的持久尾迹，P3）
CREATE TABLE audit_events (
    id         bigserial PRIMARY KEY,
    tenant_id  uuid NOT NULL,
    kind       text NOT NULL,                      -- pre_tool_use|post_tool_use|stop|...
    payload    jsonb NOT NULL,
    created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_audit_tenant ON audit_events(tenant_id, id);
```

### LangGraph checkpoint 表

`AsyncPostgresSaver` 自建 `checkpoints`/`checkpoint_writes` 等表（安装时 `setup()` 创建）。**定位**：仅承担 run 内挂起/恢复，`thread_id = runs.id`；可丢弃——恢复时以 messages 表校验图状态，不一致以表为准重建。

## 3. Redis Key 设计

| Key | 类型 | 生产者→消费者 | 语义 |
|---|---|---|---|
| `run:queue` | Stream + 消费组 `workers` | FastAPI → worker | run 派发；`XREADGROUP` 消费，`XACK` 在 run 终态后（崩溃可 pending 重投） |
| `resume:queue` | Stream | FastAPI(decide) → worker | 审批决策后的 resume 派发 |
| `events:{session_id}` | Stream | worker → FastAPI(SSE 网关) | 契约④事件流；entry id 即 SSE `id`（Last-Event-ID 续传游标）；`MAXLEN ~ 10000` 裁剪 |
| `lock:run:{session_id}` | string | worker | 会话锁：`SET NX EX 30` + 10s 心跳续期；值 = run_id（释放校验属主） |
| `idempotent:run:{run_id}` | string | FastAPI | 投递幂等：`SET NX EX 3600`，重复提交直接 202 返回 |
| `approval:notify:{session_id}` | Stream | worker → SSE | 审批通知副本（approval_required 事件已在 events 流内，此 key 供审批中心低延迟角标，可省） |

## 4. 保留与重建策略

| 数据 | 保留 | 重建 |
|---|---|---|
| messages | 永久（归档会话转冷表） | **事实源，不可重建** |
| runs / approvals | 90 天 | 不可重建（审计依据） |
| checkpoints | run 终态后 24h 清理 | 可丢弃：从 messages 表 + runs 状态重建图 |
| events:{session} | MAXLEN 裁剪，7 天 | 历史渲染走 GET /messages + approvals，不依赖 Stream |
| credentials | 永久 | 备份 + KMS 主密钥托管 |
| memories | 永久 | 可由 sessions 内容重嵌入（低优先） |

## 5. 一致性规则（写路径顺序）

1. **写穿**：Postgres messages 落库 → XADD events（表先于事件，SSE 重放不超前事实源）；
2. **审批**：decide = 更新 approvals（状态机 pending→decided，幂等）→ XADD resume:queue；两步间崩溃由 pending 重投兜底；
3. **run 状态机**：queued → running → (interrupted ⇄ running) → succeeded|failed|cancelled；`interrupted` 与 approvals.pending 对应，resume 后回 running；
4. **会话锁**：Redis 锁是运行期互斥（租约 30s/续期 10s），非持久状态；进程崩溃锁自动过期，watchdog 扫 `runs.status IN ('queued','interrupted')` 重投。
